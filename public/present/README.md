# public/present

The room screen: the built meetup web player and the event files it reads.
GitHub Pages serves it at `/present/`, next to the site but outside the
React router. A meetup page links to it in its "For organizers" line, the
page `/organizers/` lists every meetup, and the meetup page shows it in a
small, non-interactive "Preview of the room screen". `robots.txt` keeps it
out of search results.

| Path | What |
|------|------|
| `index.html`, `assets/` | The built web player from `meetup-stream-templates/web-player/dist/` in the meetup stream workspace: the script bundle, and `assets/logos/` with the community logos |
| `fonts/` | Fonts served to the player's scenes (from the same build) |
| `events/<id>.json` | One `event.json` per meetup, copied from `meetup-event-vienna/events/<id>/event.json` |
| `events/<id>/assets/` | That meetup's speaker photos and sponsor logos, when it has any, copied from `meetup-event-vienna/events/<id>/assets/` |
| `people/` | Photos shared by every meetup (organizers, recurring speakers), referenced as `people/<file>` in `event.json`, copied from `meetup-event-vienna/people/`; its README is written by the sync |
| `events/index.json` | Each synced meetup's Meetup link and id |
| `events/README.md` | One line, written by the sync |
| `README.md` | This file, kept when the folder is refreshed |

Everything except this README is generated by `npm run present:sync`, so the
subfolders (`assets/`, `assets/logos/`, `fonts/`) carry no README of their
own; the sync writes a one-line README into `events/` and `people/`. The
player build's own `events/` folder (its local copies for development) is
not copied; the event files here always come from `meetup-event-vienna`.

## Refresh it

Build the web player first, in the `meetup-stream-templates` folder of the
meetup stream workspace:

```bash
make player-build
```

Then run this from the website root:

```bash
npm run present:sync
```

This repo sits inside the meetup stream workspace, so the workspace is
expected at `..`. Point to a different one with `MEETUP_STREAM_DIR`:

```bash
MEETUP_STREAM_DIR=/path/to/aws-community-meetup-stream-all npm run present:sync
```

Everything in this folder except this README is replaced on every sync.
Commit the result so GitHub Pages serves it.

## Open it

```text
/present/?event=2026-10-20-aws-meetup-vienna-53
```

Rehearse from 17:55, ten times faster:

```text
/present/?event=2026-10-20-aws-meetup-vienna-53&at=17:55&speed=10
```

The player resolves an id to `./events/<id>.json`.
