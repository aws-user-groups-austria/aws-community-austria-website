# public/assets/sponsors

One logo per company, used by every page through the host-to-logo map in
`src/data/sponsors.ts` (sponsor wall, event cards, `/meetups/`,
`/meetups/<id>/`). Add a logo here and an entry, with its aliases, there.
A host without an entry is shown by name, never with another company's logo.
